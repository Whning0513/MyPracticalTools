# Optional writing-like-masters integration

This skill draws on the decision-based approach of [writing-like-masters](https://github.com/Fr0zenWatter/writing-like-masters), reviewed at commit `ed9e1b8800ac7a24aa1a104916470a2a5ba1a698`. That project is MIT licensed. This repository does not vendor its corpus, style files, or scripts.

Use a local copy only when the user names a scholar, supplies a style file, or asks to distill a new scholar style.

- For an existing style, read the matching `styles/<author-slug>.txt` completely. Transfer choices about structure, claim strength, notation, and rhythm. Do not copy signature phrases or imply that the scholar wrote the text.
- For a new style, read the upstream `AGENTS.md` completely and follow its acquisition and distillation routing.
- Do not download papers, clone a repository, or inspect unrelated local paths without authorization.
- If the upstream material is unavailable, ask for the named style only when it is necessary; otherwise continue with the self-contained humanization rules.
